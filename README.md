# 🌐 Pack Education

With Pack, the future of education is here. Level up your learning today, and boost your exam grades to new heights!

## 🛠 How to access
Use the live demo at the bottom of the README
### OR
- Download the project files as a `.ZIP` or clone the repo using `git clone https://github.com/matthew-seaber/pack.git` in your terminal
- Run `npm install` to install the required dependencies  
- Run `npm run dev` to start a local development server (default: `http://localhost:3000`)

## 🎨 Features
- Calendar
- Class management (for teachers)
- Pomodoro timer
- Past paper database
- Resource centre
- To-do list
- Schoolwork management (homework/tests)
- Detailed subject specifications
- Smart recommendation system
### NOTE
Some features have limited functionality at launch with a limited range of supported exam board/subject combinations. You can see the full list [here](https://www.packapp.co.uk/support) or at `/support`
